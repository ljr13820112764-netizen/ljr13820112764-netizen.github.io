「准绳」规范驱动的整改留痕助手

面向施工现场的整改留痕工具：发现问题 → 挂条文依据 → 留前后照片 → 导出可发送的留档，单点闭环。

  • 独立完成 PRD v2.2.1：先做需求判断，再写 PRD；三轮六角色模拟评审累计 21 项阻断问题，全部修订闭环
  • 手写 HTML 双端高保真原型——本页 Demo 即原型，离线可用
  • Playwright 353 项自动化断言全部通过（v2.2 / v2.3 迭代新增 53 项 + 6.3 验证点补写 84 项）
  • v2.2 全工程化落地（本地持久化 / 三路径条文关联 / 笔记导出）；v2.3 列表整理（长按 / 多选 / 删除撤销）双端同构
  • 四态状态机 + 不变量约束；条文推荐防抖防陈旧；照片压缩剥离 EXIF；导出留档页脚含自录未核验声明
  • 把「已知」与「假设」分开写：5 条核心假设标注待验证并附验证计划，未验证不表述为事实
