知数 —— 可信答案驱动的 HR SaaS（HCM）

全模块 HCM 是载体，可信答案层是差异化楔子：第一方 HR 数据在同一套权限口径下，变成权限内、可解释、可追溯的决策答案。本页是产品与工程实现说明——完整 SaaS Demo 由 Python 标准库 + SQLite 在本地运行，静态站内提供截图走查与一个可直接交互的权限对照原型。

01

问题与定位

“有数据”不等于“有答案”。中型企业的 HR 数据分散在招聘、考勤、薪酬、绩效各自的小系统里；管理层要一个数字，通常要导出多张表、在会议前手工拼口径。数字一旦被追问“怎么算的、样本多少、谁看过”，就很难自证。

知数的解法是两层：自有全模块 HCM 承接第一方数据，解决接入与口径源头；可信答案层在同一套权限与策略下产出答案卡——数据口径、数据版本、策略版本、样本门槛与抑制说明同时给出。权限之外的人看到的是“被抑制”，而不是“猜出来的近似值”。

03

可信答案层

答案卡是唯一事实源；同一张卡按接收者重算，展示口径与抑制原因，而不是把一套结果发给所有人。

机制规则
登录与会话PBKDF2-HMAC-SHA256（120,000 次迭代）；会话 Cookie HttpOnly + SameSite=Lax，8 小时
角色与数据范围服务端按角色与部门重算；字段掩码在服务端完成，前端只负责展示
k-匿名任意可见单元格样本数 < 5 一律抑制
本人组经理本人所在组门槛提高到 n < 6，并在答案卡显式标注
互补抑制仅 1 个单元格被抑制时，追加抑制最小可见格，避免反推；失败关闭
抑制上限每次最多 6 格，且不超过可见格的 30%
敏感预算单用户 10 分钟 ≤ 20 次；演示加速档 ≤ 3 次（仅演示，不改真实阈值）
维度组合10 分钟内不同维度组合 ≤ 10 种，超限统一拦截
幂等查询带 request_id，重复提交返回同一结果，不重复计数
审批24 小时未处理自动失效；不可自批；通过后限时访问 ≤ 72 小时；v1 单人审批
审计登录、查询、拒绝、拦截、审批、设置变更、演示重置均落库，含数据版本与策略版本

策略版本由规则内容计算 SHA-256；抑制与“无数据”对外使用同一文案，避免从文案差异反推真实值。对外不承诺“0 幻觉 / 100% 拦截 / 未被篡改”，只说“机制可验证、访问可追溯”。

04

工程实现与验证

  • 技术栈：Python 3 标准库 HTTP 服务 + SQLite；原生 ES modules 前端；ECharts 本地化；无 pip / npm / CDN 依赖
  • 边界：只监听 127.0.0.1；CSP 限定 script-src 'self'；数据全部虚构，仅存本机
  • 后端：8 张既有表扩展为 60+ 张表；约 50 个 API；RBAC × 数据范围 × 字段掩码统一入口；审批与审计贯通
  • 前端：18 个视图 + 抽屉 / 弹窗；hash 路由可刷新；三档响应式（>1180 / ≤1180 / ≤760）
  • 验证：API 150/150、UI 67/67、静态原型 26/26；设计 token 四条门禁全绿（硬编码色值 0、内嵌 SHA-256 同源、语义色 ΔE00 阈值、`--dv-*` 成对区分）
  • 性能：本机抽测（207 人）主要列表与聚合接口 P95 < 110ms，预算目标 500ms

08

本地运行完整 Demo

完整 Demo 的权限、抑制、审批与审计都在服务端执行，无法用静态托管承载。仓库内提供零依赖启动方式：

cd saas-demo
python -X utf8 server.py --reset --port 8770
# 浏览器打开 http://127.0.0.1:8770/
# 演示账号：a_hrd / a_mgr / a_emp / a_audit …
# 密码统一：demo1234

仅使用 Python 标准库，无需 pip 安装；服务只监听本机，数据全部虚构，首次启动自动建库并灌入种子数据。

09

诚实边界

  • 保真度分层：L1 真实可用（组织人事、考勤、假期、报表、问数、审批、审计、设置、自助、通知）；L2 规则简化（招聘手工管道、薪酬固定规则、绩效模板化、培训无 SCORM）；L3 仅展示入口（飞书 / 钉钉 / 银行代发 / 电子签 / 背调 / 多地区税务）
  • 数据：全部为虚构演示数据；租户 A 207 人 / 8 个部门，租户 B 63 人；不接入任何真实员工信息
  • 能力边界：不做多地区税务与社保引擎、招聘渠道 API、SCORM / xAPI、电子签 / 背调、AI 简历筛选、SSO / SCIM、计费与邮件邀请
  • 评审口径：项目经历多轮六角色模拟评审与定向复审，问题按阻断 / 重要分级逐条归属与修订；最近一次记录的定向复审判定为“不通过”，后续修订尚未再次复审——本页不宣称任何模拟复审判定为「通过」，也不把内部验收阈值当作对外保证
本页是求职作品集的一部分。知数为个人独立完成的产品概念与演示实现，不代表任何真实企业系统；面对客户或面试官时，能力以 L1 / L2 清单与可复现的测试为准。
